## POST 用户注册

POST /api/user/register

> Body 请求参数

```json
{
  "username": "zhangsan",
  "password": "123456",
  "email": "zhangsan@example.com"
}
```

### 请求参数

|名称|位置|类型|必选|中文名|说明|
|---|---|---|---|---|---|
|body|body|object| 是 ||none|
|» username|body|string| 是 | 昵称|none|
|» password|body|string| 是 | 密码|SHA-256加密发送|
|» email|body|string| 是 | 邮箱|none|

> 返回示例

> 200 Response

```json
{
    "code": 200,
    "message": "注册成功",
    "data": null
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|

|» data|null|true|none||none|

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|clip_id|string(uuid)|true|none||片段唯一标识|
|task_id|string(uuid)|true|none||关联剪辑任务ID|
|video_id|string(uuid)|false|none||关联视频ID|
|video_url|string|true|none||视频文件URL|
|clip_order|integer|true|none||片段顺序（从1开始）|
|start_time|number(float)|false|none||片段开始时间（秒）|
|end_time|number(float)|false|none||片段结束时间（秒）|
|duration|number(float)|false|none||片段时长（秒）|
|transition_in|string|false|none||入场转场效果|
|transition_out|string|false|none||出场转场效果|
|transition_duration|number(float)|false|none||转场时长（秒）|
|filter_type|string|false|none||滤镜类型|
|volume|integer|false|none||音量（0-100）|
|create_time|string(date-time)|true|none||创建时间|
|update_time|string(date-time)|true|none||更新时间|
